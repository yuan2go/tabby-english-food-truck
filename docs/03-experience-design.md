# 体验 · 看见需求，亲手改变局面

连续主线保持同一餐车舞台，章色、客流、食品和奖励改变局面。首页一个明显故事入口，进入后自然迎客与自动首次请求；当前目标用短字幕、声音与实物呈现。波次点/章旅程是进度信息，不是导航。水果阶段先只看到水果，甜点台、组合板、煎锅/果汁随后逐步入场。自由厨房保留所有已解锁设备。

目标至少48px，关键食品56–64px优先。点选后目标高亮，食物真实叠放/变形，热加工可见进度与原创机器声；交付接收出现朋友接物姿态、感谢、食物到席和短庆祝。奖励短停顿后自然换景，持续游戏钟拥有进度，动画无结算回调。低动态保留静态姿态/反馈、缩短表现而不改变规则。默认无强制倒计时或速度分。
