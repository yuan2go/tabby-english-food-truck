# 规则 · 活动、厨房与分享

## 三种任务的唯一判定边界

| 类型 | 判定 | 物品与记录 |
| --- | --- | --- |
| 明确订单 | REQUESTS 产品与数量多重集合严格相等，排列无关；缺、错、额外均不成功 | 明确交付才记录有字幕的请求理解尝试；错单保留全盘，不能自动转给别的客人 |
| 开放委托 | 活动配置声明有效集合/份数/类别；UI显示可选方案，规则核再次校验 | 使用同一托盘/物品实例与动作时钟，接收才进活动；记操作与选择，不能当独立听力 |
| 自由制作 | 任意合法配方与可食用成品、最多三份，无订单标准答案 | 真实输入消耗/输出；作品保存为记忆快照，食品仍只在一处；不发订单成绩 |

配方来自 src/content/recipes.ts；订单来自 catalog；本包活动内容来自 content/adventure.ts，判定与进度由 rules/adventure.ts。Phaser/DOM只投影，不复制规则。

## 活动因果

第三章开场兔兔明确要芝士三明治，刺刺明确要蔬菜三明治，两个请求配置固定，单客由玩家选择哪位先入场；已接请求固定。首份在角色接收阶段完成的交付决定路径：

- 兔兔先：可检查篮子，看到还需要一份三明治和一份水果；实际制作并可逐份放进篮子（两种三明治与苹果/香蕉均有效），随后把篮子放上野餐桌。
- 刺刺先：已交付的两份食品保持在两位朋友原位，直接选桌布布置，不能复制或再回营业库存。
- 另一个朋友仍照原单服务，无晚服务惩罚。两路都需两份明确订单和自己的操作，再铺桌布、分享，得到同一野餐食谱页和桌布；选择与实际食物留下记忆。

其他章：两份早餐真实接收→主动一起吃早餐，自然收尾；抽屉/花苗/水壶/种花/浇水/蝴蝶保留为可选探索，不是早餐完成前置；冰淇淋明确订单＋不同杯装口味委托→场景比较两份真实甜点→品尝；彩旗自选；汉堡与饮品真实交付→直接安排朋友带灯或杯→原位布光；社区邀请听回访需要→自由成品拼盘→按类别分享并品尝→保存实际作品→开席。探索对象给具体线索、物件或新动作，不作导航装饰。

## 单归属、加工与交付

供应仅在合法落点产生唯一 food ID；起拖/取消不生成。托盘两只各三格，不设隐藏无限库存。机器、组合板、助手和交付持有真实实例。配方完整输入才能产生输出；手工叠放/挖球自然完成，煎锅和果汁需启动并运行有效加工钟。输入原子消耗，器具也有实例。READY不烧焦，取走释放设备。

加工/助手/交付由唯一有效游戏时钟推进。热加工启动绑定真实输出位置与容量预留；旋转、刷新不改绑定；历史旧盘预留继续有效。机器动画不能完成任务；有效接收阶段才移交食品与活动进度，重复指令/读档不重复奖励。暂停、帮助/显式教学、后台停止时钟，不补离线时间；普通参考/编辑便签不中断其他工作。

已交付食物从营业库存移到活动持有物：品种、数量、状态一致，可摆放/品尝，不能重回供应。活动桌上的食品可拿回作品区并重新安排座位，仍由活动持有，不回营业库存。作品保存截取最近一次实际作品组的最多三份成品（直接逐份分享属于同一拼盘组），旧活动作品在食谱里可回看；图文记忆不创建食品。品尝改变该实例状态；记忆保留实际作品组成和位置。活动、奖励、探索与记录有界。

大咪同时一个动作、有界队列；助手仅拿苹果/香蕉，最多两份，原子预留，取消归还/释放；不读取订单答案，不自动完成整单。只有交给大咪才有便签表达尝试。词块独立ID，a/an/one/two/and有限语法，大小写/标点归一，incomplete/outside/结构调整/世界受阻分别反馈。

## 自由营业与重玩

菜单可选已介绍内容，主题只过滤新任务池，seed/cursor保留；恢复开店时先应用本次菜单与主题，再补足新增客流，旧订单原样保留；新任务数量/设备/原料可达，最多两客。停止接客后保留已接单、食品与加工，允许做自由拼盘和作品，主动收摊回院保存。重新开店接续同一厨房；重玩活动另起run，不重复累计礼物，不清除过去作品与历史帮助。

## 无死局与支持

设备满、两盘满、助手预留、错误成品均有取走/撤回/放回/直接收起及恢复路径。成品不能还原原料；错单整盘保留。支持策略不裁剪错误选项，也不替玩家选客户；双客必须明确目标。

重听不惩罚；默认英文字幕记录为caption-visible，不与额外图示/示范/错误解释或纯听力混算；历史支持不能洗白。发音开发版未审核，播放事件只证明播放。小游戏/教学库存隔离，拼写与结构不锁活动。不能把纯操作错误写成英语错误。

## 活动深化与恢复边界

单客初始朋友等在院边，由玩家点角色迎入；完成当前接待后仍由玩家选下一位。双客同时接待；从双客切到单客不赶走已接朋友，随后才限制新增接待。请求与身份稳定；先选择朋友不产生野餐分支，错单与播放也不产生分支。

活动新增体验字段只记录实际取用工具、协作安排、回访需要、食品使用者与有界演出收据。旧未完成档补空字段，不推断浇水、对比、协作或回访已完成；原奖励收据保留，不将已完成活动重新锁住。新跑次完成要求在规则中明确，不由UI猜测。

花苗与浇水工具可从抽屉取出并用于花的位置；第二章可比较两种真实甜点并把旗当分享遮阴；野餐篮内实际内容与缺项图示一致，刺刺路线原位分餐布置；第四章直接安排朋友带杯/灯后原位布光；第五章及自由阶段邀请的朋友依据实际过去活动和已接收食品提出有限开放分享需要。多解需要按声明类别/数量判定，错误分享保留原食品；自由作品本身始终无答案。

食品到桌、携带、摆放、品尝与回应使用真实实例与使用者。已品尝食品不能再充当新的分享；餐位满时先拿回已有食品，再重摆。收拾已完成章或自由店桌面会释放对应分享牌的食品引用，保留需要类别、已接请求、旧作品与奖励；未完成第五章仍要用新作品实际分享和品尝再完成。品尝每份只结算一次；跳过、重听、低动态、取消和刷新只改变表现，不能重复消费、发奖或推进。保存作品记录组成、位置与实际使用，回看不能复制为库存；拿回、换位、继续搭配及重新制作形成修改路径。额外探索/作品/回访不给英语独立能力分。

## 小游戏规则合同

寻物：可见大热点，先点拿起再点交付篮，真实物件移位；记忆：无计时观察→主动遮挡→补回缺物，可重看，错误只记memory-adjust；整理：点物再点具象容器，按类别/用途/属性，配置声明多种合法容器；布置：实际餐桌位置判定方位/份数/属性，自由模式无标准答案与语言成绩；剧场：打开容器才可取出、倒水前需拿起壶/放好杯、搅拌前有水、清洗/切分/搬运/分享改变对象状态，角色响应实际操作；不排列文字卡播放固定片段。

每次只介绍最多4词。同词听音与配对均有真实图像/动作入口，场景适合的词再参与寻物/记忆/整理/布置/剧场。短请求独立登记，count/mass、复数和有效多解由内容/规则核决定。随机只排可用物件，seed与题号保存，刷新不换题。

状态变更不是语言尝试；明确交付/检查才记当次结果，操作、记忆、识字和语言分开；未完整听到时记录audio-not-observed，重看/示范/图示帮助保留。无倒计时、生命、奖励经济或强制复习；场景完成收据去重且不动营业库存。

当前实施/验证见[05](05-delivery.md)和[STATUS](STATUS.md)；历史授权、已替代阶段计划见[归档](archive/pre-demo-repair-2026-10-12/index.md)。

## 英语行为合同

台词由语义生成并绑定唯一整句资源；标签可为单词，请求不能只用Two apples等名词片段。明确请求表达全部严格约束（如杯装、蛋筒、口味）；合法产品与数量判定仍由原规则决定，托盘顺序不影响。开放请求描述规则核允许的范围，所有合法替代方案继续有效。

动作前请求、动作后示范、成功反馈有不同触发条件。接收感谢仅在规则receive转移后；品尝评价仅在真实tasted改变后；制作提示依实际设备/输入，不播放答案或每点一次播一句。小院找物/抽屉/打包/摆餐/种花/挂旗/灯/邀请/作品保存接入少量行动语言；失败不虚构结果。主动分享由实际create/invite/place选择产生大咪代读，作品英文组成与回访对应真实食品/历史收据，无历史不说remember。自动播放/代读不产生语言尝试或奖励。

## 直接制作与有意义完成（现行）

原料在对应设备旁直接操作：ingredient(product,target)原子生成唯一输入并放到明确设备。手中有食品或活动工具时不得被直接制作静默替换，失败保留食品、时钟、容量与学习记录。普通拿取/拖放仍调用同一规则。

冰淇淋选杯/筒后点口味即产生合法成品，不设接好或加工等待；杯装成品仍留在冰淇淋台，可按现有合法配方继续加球/香蕉。直接挖球不是订单提交；取走后点明确朋友才判严格语义。三明治直接叠放面包与夹层，第二片面包自然封合；汉堡熟饼与圆面包/配料直接组合。组合无独立确认或设备时间，肉饼仍真实煎制3500ms，果汁仍5000ms。配方产品/输入/数量不扩张；新增命令不代选正确原料。可撤回未合成输入，冰淇淋可取回重新放置；成品收起直接可恢复，不再先弹确认。

所有已开放设备各自显示任务与输入，启动煎锅/果汁机为唯一加工开关。不用family或视图状态决定投料。键盘、点击、拖放走同一命令；设备忙、满盘、落空等只记操作受阻。

章节结束仍由玩家主动一起吃/开席：第一章两份早餐接收即可，探索自选；第二章两份不同真实甜点在场景比较及实际品尝即可，食谱/小勺/彩旗不作完成门槛；第三章首份真实接收决定双路线，兔兔路线可逐份向篮子装一份三明治和一份水果，再摆上桌，刺刺路线直接选桌布布置原位两份餐，两路奖励等价，取消抽屉/餐垫/重复搬餐前置；第四章真实汉堡与果汁接收、玩家安排一位朋友带灯且选灯光即可，设备与灯同时可达；第五章实际邀请、自由制作、至少一次有效分享与品尝、保存真实作品后开席，食品可直接分享给朋友，作品保存在场景食谱物件发生。

已接收食品在原位显示。场景比较/品尝和保存从实际食品发命令，无UI通关。装饰是玩家直接选择并立即摆好，不经过拿装饰再找放置按钮。所有历史奖励、食品、帮助、订单与加工旧档保留，新增行为不从动画推断。旧content together-play-1在完整校验后迁移；未完成章只按新合同检查实际行为，不自动授奖。

小游戏默认从选定组直接进入可操作场景，新词意义图片与英文名在当前玩法内显示，示范与例句可选；已展示答案保留支持记录，记忆遮挡后不展示缺物答案。仅记忆玩法保留真实观察→遮挡动作；成功反馈后一次下一轮直接进入下一可操作场景，不重复认识/开始；拼写及组句仍自选。状态变化、检查/交付与音频记录保持原边界，不自动提交高级文字题。
