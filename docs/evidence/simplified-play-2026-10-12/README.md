## 实际变化

食品真实位于hand:0–2，以唯一实例拿取、放下、放回；多件失败先在规则核预检，原状态原子保留。明确设备目标决定投料，不依赖family浏览状态；真实加工时钟、成品取出、配方消耗、容量与预留沿用原核。朋友和其前盘等价交付，气泡仅重听，空地不提交，误送不自动找正确对象或接单。早餐实际收到两份食品即可主动开席，花苗/浇水随后可选；旧存档只在有效既有收据及食品位置证明下迁移摆餐事实，不增加尝试、探索或奖励。

旧独立剧场、分场景React入口、端盘/选盘/模式管理及旧Phaser渲染器已删除。角色按Alpha可见轮廓及脚底锚点归一，同一角色同屏一次，原位置接收/品尝。手机核心物件/语义目标48px起，无核心场景滚动；可点击、键盘Enter/Space，拖动可选并宽容吸附，取消/后台/多指不改变库存。设置、便签和恢复在暂停内，图示与同场示范保留真实支持记录，示范/重播不创建食品、交付尝试或通关命令。
