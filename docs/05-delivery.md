# 交付与验收 · WP-ENGLISH-IMMERSION-01

**Goal:** 完整英语贯穿点餐、制作、交付、小院真实行动、分享与历史回访，默认英文可见且整句可重听。
**Architecture:** 语义语料统一生成文本与整句资源；既有规则核提供真实事件，单一前景音频通道取消播放，DOM呈现与操作互不替代。
**Tech Stack:** 现有锁定React/Phaser/TypeScript/Vite；不新增依赖。
**Spec:** 01范围、02规则、03体验、04工程为唯一权威。
