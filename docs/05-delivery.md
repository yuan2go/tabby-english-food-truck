01–04是现行产品、规则、体验和技术权威；[STATUS](STATUS.md)报告实际结果，[证据索引](evidence/README.md)提供受测版本。本文保留验收标准，不重复已完成的阶段实施计划或临时Git授权。

## 游戏行为标准

| 范围 | 必须证明的行为 |
| --- | --- |
| 任务与学习 | 严格订单内容/数量准确；开放委托有效多解；自由制作无订单答案；错单留食品，支持不洗白，操作/记忆/识字/语言分开 |
| 五章与分支 | 每章实质动作不同；首次真实接收才定野餐路线，两路不同操作且等价汇合；已接请求固定 |
| 世界与作品 | 交付食品实际用于摆放、分享、品尝；工具/装饰有用途；作品可改位、保存、回看，不复制库存 |
| 自由营业 | 菜单/主题只影响新客；停客保留加工和已接任务，继续作品、回访、收摊及重开 |
| 十类小游戏 | 真实物件、数量、属性、空间和状态前置；可帮助、撤回、重看、退出回来源；不锁主线 |
| 守恒与恢复 | 单实例单归属；有效时钟、输出盘绑定、重复接收/演出去重；旧档不虚构新完成，坏/未来/拒存保护原文 |
| 触控与可达性 | 手机/Pad点击操作与桌面等价，拖动可选；关键目标可见可点，模态焦点受限；重听不误交付 |
| 音画 | 图示可恢复，较少帮助不泄严格答案；播放失败不作语言错；资源真实接入并有来源/权利记录 |

完整共享核验证只在规则/库存/快照风险需要时运行；浏览器从正常入口操作，不注入通关、不放宽规则断言。当前实际失败见STATUS，不将上述标准写成已满足结论。
