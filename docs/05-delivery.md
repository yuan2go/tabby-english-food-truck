# 交付与验收 · WP-PLAYABLE-ADVENTURE-01

**Goal:** 五章共同活动贯通、野餐真实双路径、自由厨房/开店/成长/恢复完整可玩。
**Architecture:** 单一规则核增有限活动状态，真实接收驱动任务与分支；规则、表现、保存各负一责。
**Tech Stack:** 现有锁定React/Phaser/TypeScript/Vite；不新增依赖。
**Spec:** 01范围、02规则、03体验、04工程为唯一权威。

## 验证与公开边界

只测本包实质风险，复用现有测试，不注入通关、不删关键断言或扩无关视口。共享物品/快照风险导致完整单元回归；浏览器正常路径用正式按钮/指针，状态读回只证明守恒，不当儿童观察。简单展示不大量加测试。

手机模拟、桌面、实体设备、教研、听审、儿童观察分别报告。工程PASS不等于VISUAL_ACCEPTED/DEVICE_VALIDATED/CONTENT_REVIEWED/FUN_OBSERVED/PUBLIC_RELEASE_READY。外部验收PENDING/NOT_RUN不阻断独立工程。历史性能60fps NOT_MET不自动改为通过。
