# 交付与验收 · WP-ADVENTURE-EXPERIENCE-02

**Goal:** 在完整五章、两条真实野餐路径与自由厨房上，使不识字玩家理解目标、主动尝试并看见朋友使用食物。
**Architecture:** 单一活动规则核接通客流、工具、分享与守恒；只读引导与独立演出投影事实；现有音频/存档负责生命周期。
**Tech Stack:** 锁定React/Phaser/TypeScript/Vite，不升级依赖。
**Spec:** 01–04为唯一产品权威，本文仅实施顺序和验收，历史方案见[索引](archive/pre-adventure-experience-02/index.md)。

## 简短实施计划

- [ ] 0 只读核查最新main、提交、界面/控制器/规则/音频/存档/资源；归档过期正文、修引用、独立文档提交。本勾选仅表示治理。
- [ ] 1 客流接通：rules/adventure、sessions、game、controller、Story/App；单客主动迎入、双客与切换保留。针对首次真实接收/两路/刷新/已接请求补失败回归，再实现并提交。
- [ ] 2 活动深化：content/adventure与独立规则使用/工具/回访模块；补齐五章有效动作、篮内缺项、工具取用、不同布置及熟客需要。验证物品/奖励守恒、多解/严格/自由边界与旧快照恢复。
- [ ] 3 无识字与朋友使用：只读规则引导、独立场景图示/朋友演出/物件组件；正常输入实现重听、静音图示、较少帮助不泄答案；制作并登记必要情境音频。只对实质风险加测试。
- [ ] 4 合并必要检查：完整共享核单元、lint、build内typecheck、resources；正常入口走完五章，单/双客、野餐另一路、自由作品与音画反馈，代表手机393×665和桌面1280×720。留少量截图/短录像、构建SHA/日志；修真实失败。
- [ ] 5 同步STATUS/相关权威与资源记录，阶段提交、推送、PR。未经本次授权不合并、不部署、不强推、不覆盖其他改动。

## 验证与交付边界

只验证本包风险，复用测试；共享核/存档变动需完整单元。浏览器通过正式可见入口，不注入通关、不削弱断言、不扩无关设备矩阵。自动化通过只证明观察到的行为，不证明儿童独立理解。负责人手感/真机/儿童/教研/人工听审/权利/性能逐项如实记PENDING、NOT_RUN或已有失败；历史60fps NOT_MET、真机NEEDS_REVISION保留。

交付记录baseline/final full SHA、分支/PR、行为、必要命令/退出码/环境、实际浏览器HTTP路径与限制。启动npm ci、npm run dev或build后preview。GitHub源码不是可玩网址。上一包合并授权已在归档明确，不作为本包授权。
