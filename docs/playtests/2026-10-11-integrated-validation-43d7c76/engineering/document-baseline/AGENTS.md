## 核心不变量

- 规则是唯一事实来源；Phaser、React、帮助和自动化测试不得各有一套订单判定。
- 食物只有一个归属，配方明确消耗输入并产生输出。设备工作需要有效任务及游戏时钟，不能由动画回调直接完成订单。
- 默认允许慢想、重听、放回、撤回便签和重新准备。触控落空、未装满、设备忙、存储/音频失败不是语言错误。
- 订单按内容和数量匹配，托盘摆放顺序不影响正确性。语言结构、语义、情境、实际动作分别判断。
- 新知识先表达意义；辅助、教学、示范、独立和回访记录分开。看过答案不能撤销成独立完成，游戏速度不等于英语水平。
- 只有用户实际确认交付或便签时才产生相应语言尝试；自动语音与角色表演不是用户提交。
- 关键文字由游戏文字层/必要 DOM 绘制，不烘焙进背景。图片入库不等于已接入运行页面。
- 使用已确认棕灰虎斑、金色眼睛、浅口鼻、灰项圈、绿色围巾；白色定位器在画面颈部偏右，不镜像改变位置，不被围巾遮挡。

## 工程、安全与验证

TypeScript 严格类型、明确边界校验、真实锁文件、可取消生命周期和可恢复本地快照。依赖版本先验证再锁定，不盲目升级；默认不引入运行时模型或后端。所有第三方模板遥测和素材许可证须核验。

只运行当前风险需要的检查；修复真实失败，不堆快照、删除断言或注入通关状态。手机模拟视口、桌面浏览器、实体设备、教研与儿童观察分别报告。性能目标不是测量结果。

不提交密钥、儿童个人信息、公司内部资料或未经授权的品牌/声音。开发语音明示未审核。没有真实审核者与记录，不得标为已审核、好玩已证明或公开可发布。外部审核阻塞对应环节，不阻断能独立完成的工程。

一包一个实现负责人。默认独立分支/worktree、阶段提交、推送、PR，不自动合并、强推、改权限、启用工作流或覆盖无关修改。空仓库首个 README 初始化除外。部署另行核对授权和目标站点，不把 GitHub 源码链接当可玩网址。

交付包含 baseline/final full SHA、分支/PR、行为变化、测试命令/退出码/环境、实际浏览器路径和限制。更新 STATUS 与相关权威文档，不以文档数量作为产出。未执行写 NOT_RUN，外部限制写 BLOCKED/PENDING。
