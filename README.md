# 狸花猫的英语餐车 / Tabby's English Food Truck

一个从零设计的儿童英语触控网页游戏：听懂请求，准备食物，安排柜台，与狸花猫一起完成交付。

仓库：`yuan2go/tabby-english-food-truck`。
