# 大咪的英语餐车 / Dami's English Food Truck

**听懂请求，动手准备，和大咪一起把每一份心意送到客人面前。**

独立仓库：`yuan2go/tabby-english-food-truck`。这是从零设计的单人、触控优先儿童英语网页游戏，不是英语学习网站或餐厅管理系统。

当前 M2.2 面向3–6岁：小院首页组织故事、无尽营业、小游戏和教学练习；长辈交接餐车，果汁、冰淇淋、三明治、汉堡推动四章成长。支持策略独立于模式，默认无需识字和拖动。英语提供需求与协作信息；准备顺序、设备占用和有限台面形成游戏选择。默认没有惩罚倒计时，不要求每次拿食材先答题。

## 运行与检查

使用 Node >=22.12、npm，首次安装浏览器后从本目录运行：

```sh
npm ci
npx playwright install chromium
npm run dev
```

开发入口为终端显示的本地 HTTP 地址（默认 http://127.0.0.1:5173）。生产预览：`npm run build` 后 `npm run preview`。不通过双击 index.html 运行。

| 命令 | 实际用途 |
| --- | --- |
| `npm run typecheck` | 严格 TypeScript 检查 |
| `npm run lint` | Biome 格式与代码规则 |
| `npm run format` | 格式修整 |
| `npm test` | 纯规则、语言、快照与生命周期测试 |
| `npm run build` | 类型检查与 Vite 生产构建 |
| `npm run resources` | 校验真实资源尺寸/字节/hash/Alpha/引用 |
| `npm run test:browser` | 构建生产包，以 HTTP 启动 Chromium 操作测试，保留录像 |

资源重新导出：`node scripts/export-assets.mjs` 与 `node scripts/export-character.mjs`、`node scripts/export-m2.mjs`；只有确实更新生产文件后才运行 `node scripts/manifest.mjs` 重登记，再执行资源检查。不要靠改清单掩盖坏资源。原稿、来源、权利与审核见 [art/README](art/README.md)。

## M2.2 操作说明

小院有故事／继续故事、无尽营业、迷你游戏和教学练习四个场景入口，旁边的音符可听入口介绍。故事从可跳过／重看的钥匙交接开始，19个内容请求贯通果汁、冰淇淋、三明治、汉堡与社区小食会；章节完成会增加食谱页与小院装饰。故事和无尽分别选择示范、图片、较少辅助，教程完成记录独立于本局。教学练习可回访已介绍的食谱。

1. 水果点食品→送餐，共两次主要操作。点机器进入制作，点水果→启动→送餐，共四次；非教学目标空杯由规则生成真实实例。
2. 点冰淇淋台／组合板／煎台选择工作对象，再点配料。汉堡煎好的饼直接进入已绑定的组合板；加工成品进入启动时预留的托盘位置，切换或刷新不换盘。
3. 点客人气泡重听；点大咪打开按需帮助。单客点送餐即可，双客须明确选择客人，送餐按钮不依据答案启用。多食谱用轻量食谱入口切换。
4. 原料点一下立即选中，再点同一份可退回；也可用旁边的“放回这份”。成品收起需确认，能恢复原成品，不还原原料。拖放与键盘等价，错误交付保留食品。
5. 暂停一级只有继续、设置、保存回首页。声音或保存失败收敛为小状态入口，可按需重试或导出。
大咪便签支持图片协作与可选水果词块，只有实际确认才提交；撤回释放预留。角色取料、递交与返回串行衔接，设备可并行，规则时钟决定物料转移。暂停、显式教学、后台停止任务，返回小院保存，重新进入继续。

教学入口的五篮食物每次展示五项，可听50种食品名称和情境表达并进入找图练习。直接水果、配方配料、预制供应、仅认知分别标识；只有可供应内容能加入菜单。新资料无尽先接苹果，营业间隙可选择认识香蕉、果汁与香蕉汁并加入菜单；帮助、语言负荷和客流分别设置。

小游戏每组四题，随时回游戏小摊，各玩法分别保留草稿，可继续或明确重开。初始为听音找图，识字玩法与帮助/字母基础放在“换帮助或玩法”：听词找图／英文配图／识字后的中英配对；WordSpell按已介绍内容与字母基础选词；示范、部分补全和自己试提供不同补全量，ice cream保持两个词组。重复字母各有ID，点按、拖动、撤回及重排共用规则。字母库仍是支持条件，不宣称完全无辅助拼写。拼写不解锁故事，也不修改营业库存。

详细声音、画质、导出、完整构建SHA、资源版本与成人学习观察放二级设置。记录词义、听请求、拼写、基础结构与操作，不显示掌握率；开发语音明确未听审。M2.2使用schema6、Profile v3与独立活动保存，明确迁移世界schema3–5和Profile v1/v2，M1原文保留并可导出，不能可靠推断的故事进度不猜迁移。当前题已使用的帮助不能通过撤销、刷新或支持策略切换洗掉。

不 fork、不导入旧提交，不读取或复制旧项目的页面、组件、样式、关卡、状态模型、存档或工作包。产品目标与确认的狸花猫形象可以延续，但旧资产不得自动搬入；需要逐件确认用途、质量和来源。旧仓库保持原状。
