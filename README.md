# 狸花猫的英语餐车 / Tabby's English Food Truck

**听懂请求，动手准备，和狸花猫一起把每一份心意送到客人面前。**

独立仓库：`yuan2go/tabby-english-food-truck`。这是从零设计的单人、触控优先儿童英语网页游戏，不是英语学习网站或餐厅管理系统。

当前 M2 面向3–6岁：小院首页组织故事、无尽营业、小游戏和教学练习；长辈交接餐车，果汁、冰淇淋、三明治、汉堡推动四章成长。支持策略独立于模式，默认无需识字和拖动。英语提供需求与协作信息；准备顺序、设备占用和有限台面形成游戏选择。默认没有惩罚倒计时，不要求每次拿食材先答题。

## 运行与检查

使用 Node >=22.12、npm，首次安装浏览器后从本目录运行：

```sh
npm ci
npx playwright install chromium
npm run dev
```

开发入口为终端显示的本地 HTTP 地址（默认 http://127.0.0.1:5173）。生产预览：`npm run build` 后 `npm run preview`。不通过双击 index.html 运行。

| 命令 | 实际用途 |
| --- | --- |
| `npm run typecheck` | 严格 TypeScript 检查 |
| `npm run lint` | Biome 格式与代码规则 |
| `npm run format` | 格式修整 |
| `npm test` | 纯规则、语言、快照与生命周期测试 |
| `npm run build` | 类型检查与 Vite 生产构建 |
| `npm run resources` | 校验真实资源尺寸/字节/hash/Alpha/引用 |
| `npm run test:browser` | 构建生产包，以 HTTP 启动 Chromium 操作测试，保留录像 |

资源重新导出：`node scripts/export-assets.mjs` 与 `node scripts/export-character.mjs`；只有确实更新生产文件后才运行 `node scripts/manifest.mjs` 重登记，再执行资源检查。不要靠改清单掩盖坏资源。原稿、来源、权利与审核见 [art/README](art/README.md)。

## M1 历史操作说明（M2实现后更新）

首页有三个小入口，首次默认“跟着小猫做”。进入后用场景内实物、语音与小猫拿放演示表达意义，再点“我来试试”。不需要先识字、编辑便签或读三页说明书。主要路径是先点食品、再点目标；拖放等价，Tab/Enter/Space 调用相同规则，Esc 取消拿取。

- **跟着小猫做**：一客一盘一个苹果；重玩体验预放杯的苹果汁，明确记录为引导支持。
- **帮客人准备食物**：一次接待一位，五个请求覆盖苹果、香蕉、两个苹果、组合、苹果汁；新知识先短演示，图示按需打开，可随时重听。
- **小小餐车营业中**：双客双盘，果汁加工 5 秒期间可以准备另一盘。单果、数量和组合可请助手，词块便签为可选进阶路径。

苹果放机器上方入口，空杯放右侧杯座，按启动；真实完成后取走杯中果汁。选盘把手再点客人，或拖整盘到客人，食品始终随盘；拖盘里单个食品只做编辑。错误交付保留食物，满盘可放回或换盘，果汁清理需要确认。

点小猫打开图片请求或词块便签（例如 `An apple`、`Two apples`、`An apple and a banana`）。提交绑定当前盘并预留全部槽位；猫分别去苹果/香蕉格取料、携带、落盘，切换选中盘不改变目的地。可撤回并释放全部预留。

暂停、帮助教学、失焦和后台停止任务，不补算离线时间；便签编辑和普通拿放继续加工。切换玩法保留各自库存与进度，重玩仅重置当前模式；帮助/示范/解释历史不被刷新或切模式擦除。快照 schema 2 / 内容 m1.2；旧 schema 1、未来版本和损坏数据保留原文导出后明确重开，不猜测迁移成绩。浏览器拒绝存储时，本次模式切换仍保留内存快照，离开前需导出。

暂停页提供总静音、英语/音乐/环境/音效分项控制及低画质选项。英语期间背景和机器压低；后台停止循环和旧音效。暂停页“构建与资源”可查看实际完整 SHA、脏工作区标记、内容版本与资源清单 hash。

## 独立重启边界

不 fork、不导入旧提交，不读取或复制旧项目的页面、组件、样式、关卡、状态模型、存档或工作包。产品目标与确认的狸花猫形象可以延续，但旧资产不得自动搬入；需要逐件确认用途、质量和来源。旧仓库保持原状。

首版以 Phaser 游戏场景为核心，TypeScript/Vite 构建，React 仅作薄外围与无障碍 DOM 层；具体依赖版本在新工程冒烟通过后锁定。不使用旧项目 lockfile，不把官方模板示例 UI 当产品设计。
